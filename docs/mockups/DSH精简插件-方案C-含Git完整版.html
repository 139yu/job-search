▶ Git 操作交互说明（提交 / 推送 / 拉取 / 抓取）
提交:变更 tab 底部输入 commit message → 点「提交」→ 仅提交已暂存文件;提交成功后变更列表清空、Git 图刷新、账本不受影响

推送:工具条「推送」→ 本地领先(↑2)时可用;成功 → 状态条「✓ 已推送」;失败(远端被他人更新)→ 提示先拉取,不覆盖

拉取:默认 fast-forward;有分叉时弹确认:「合并(main 并入本地)」或「变基」二选一

抓取:只更新远端引用(origin/* 线),不合并,刷新 Git 图即可见远端新提交

冲突:拉取/合并冲突 → 冲突文件标红、Git 图显示 MERGING 状态,解决后继续提交

权限:所有 git 写操作(提交/推送/拉取/抓取/暂存/还原)执行前都会弹确认,只读操作(树/预览/图)不需要
