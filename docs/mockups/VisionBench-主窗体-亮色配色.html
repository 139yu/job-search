逐区内容与配色说明（①-⑥ 对应上图编号）

落地方向：每个区域按 RegionConstants（MainNavRegion / LeftBarRegion / HalconRegion / MotionRegion / RightBarRegion）拆成独立 UserControl 后填充。

#区域（RegionConstants）网格位置 / 尺寸要填的内容配色要点
① 标题栏
WindowTitle		 Row 0 · 30px · 跨 3 列 应用名 + 版本副标；运行状态徽标（相机在线 / 轴状态 / 当前配方）；最小化 · 最大化 · 关闭 底 #E8EDF3，标题字 #0F172A；状态点用 OK 绿/Accent 蓝；关闭悬停 #DC2626
② 主导航
MainNavRegion		 Row 1 · 50px · 跨 3 列 菜单项：相机设置 / 运动设置（已在 VM），配方管理 / 系统（规划）；右侧显示当前配方与运行模式 底 #EEF2F7；选中态 = #DCE8F8 底 + Accent #2B6CB0 2px 底线；未选中文字 #475569
③ 设备与参数
LeftBarRegion		 Col 0 · 300px · Row 2-3（跨两行） 设备树（相机 / 光源 / 运动轴，各带状态圆点）；当前项参数表单（曝光 / 增益 / 触发模式 / 像素格式·ROI）；[应用] [抓图] 按钮 白底 #FFFFFF；树选中 #DCE8F8 + Accent 字；圆点 OK #0D9488 / 离线 #B8C5D6 / 轴 Accent；主按钮 Accent 实底白字
④ 图像视口
HalconRegion		 Col 1 · Row 2 · 1* Halcon HWindow 图像视口：网格 + ROI 框（虚线 + 十字线）+ 检出轮廓；左上信息条（窗口/分辨率）；右下实时 legend（FPS / ROI 数 / 结果 / 耗时） 唯一深色例外：底 #12161C、网格 #1C2430、标签 #94A3B8；ROI 线 #60A5FA；轮廓 #0D9488
⑤ 运动控制
MotionRegion		 Col 1 · Row 3 · 0.6* 轴选择 X/Y/Z/R；目标位置 + 速度输入；点动 Jog±；[相对移动] [回零] [停止]；实时位置 / 速度 / 状态 / 目标差读显 白底；选中轴 Accent 实底白字；动作按钮语义色：[相对移动] OK 绿、[回零] Warn 琥珀、[停止] 默认灰；状态字 Accent
⑥ 日志与结果
RightBarRegion		 Col 2 · 400px · Row 2-3（上下两半） 上：运行日志（时间戳 + 级别着色，带 [清空] [导出]）；下：测量结果表（项 / 实测 / 公差 / 判定）+ 统计条（合计 / 节拍 / 良率） 白底；日志级别色 OK/WARN/ERR，普通行 #64748B；判定 PASS #0D9488 / NG #DC2626；统计数字 Accent

搭配原则（落地 Theme 时遵守）

  • 大面积只用灰阶：App / Title / Menu / Panel / Border 形成 4～5 级浅色层次，不用多色块铺底。
  • 彩色只留给交互与结果：Accent 蓝 = 选中/主按钮/焦点；Teal = OK；Amber = 警告；Red = NG / 关闭悬停。
  • 图像区可单独深色（--vision-bg），其余保持亮色，不影响「整体亮色」观感。
  • 无圆角卡片风：与无边框 WPF 窗体一致，区域靠分割线分层，避免 Web 卡片阴影。
  • 正文对比：#0F172A on #F4F6F9 / #FFFFFF ≥ 4.5:1；次要字 #64748B 勿再叠灰底。
  • 本次范围：仅细化设计稿内容与标注，DefaultTheme.xaml 与 MainWindow.xaml 均未改动；定稿后再决定是否同步色值 / 落地布局。
